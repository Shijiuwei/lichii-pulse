Static library shader sweep, 2026-11-04

This is a partial library sweep, not an all-games pass. The inventory identifies 16 titles. Static readers extracted 26,510 distinct code/control allocations from eight of them, representing 17,916 distinct stage/bytecode combinations. Three independent fixes remove lowering failures from 1,043 distinct bytecode programs. The other eight titles still need another asset reader or a guarded runtime capture.

No game was launched for this sweep. The owner had lichii.exe running, so the approved no-GUI safety condition prevented fallback boots. All library access was read-only. Exported data, logs and builds stayed in separate scratch directories; no key files were needed or transferred.

What the counts mean

The baseline compiler is nx2 935c5bdb03. The comparison adds only these changes:

FixCommitEvidence
Bananza BRA.U, #55ae4a50d6a780e40c06ac7a711fd70b4e55a91ac9All 814 original rejected fragment captures lower afterward.

The expanded corpus also exercises padded compute allocations. Across all retained control variants, native-lowering successes rise from 24,208 to 26,045. Lowering failures fall from 2,072 to 235; another 230 allocations cannot establish a supported, complete native instruction envelope. No previously lowered allocation regressed. The 1,837 newly lowered allocations represent 1,043 distinct bytecode programs: 814 Bananza, 228 Duskbloods and one Fast Fusion program.

These are lowering results, not evidence of correct rendering. All 1,837 newly lowered allocations next lack runtime specialization context. The inspected Bananza runtime logs contain no branch-convergence rejection, so #55 has no demonstrated in-game effect in those sessions.

Full replay of the separate, preserved runtime-cache corpus is unchanged: 10,170 of 12,598 environments validate with spirv-val before and after; 2,428 retain their known context gaps. This checks already captured environments, not the never-played variants in the static archives.

For static allocations, 1,275 emissions validate with a compatible cached environment, and 4,488 validate with explicit synthetic pipeline defaults. Both are partial, not captured pipeline successes. Cache association is inferred from title, stage, identical lowered instructions and, for graphics, identical 80-byte shader headers. The output records all matching cache candidates and the one selected for replay. It does not establish that this archive variation used that environment at runtime.

All four current NUPs were cataloged with Lichii's NupContainer and RealVFS. Explicit export of 30 shader-named members from Bananza and Mario Kart World yields the same shader identities as their loose counterparts, so those are not counted twice. The empty [0] NUPS directory is not a title.

The extraction manifest has 103 diagnostics: 95 archive/member diagnostics and eight inventory entries needing separate selection or a different reader. These include duplicate NUP entries and the empty directory, not 103 distinct bad shaders. Unsupported BND4 variants, Kraken DCX payloads, legacy shader binaries and metadata members remain visible in that report.

Remaining compiler failures

The before and after tables group diagnostics by game, stage, phase and opcode. Counts there are code/control allocations.

The largest remaining native failures include Duskbloods global reduction modes at 0x98e, Sports Resort 0x4a4, Raiders multiply-wide addend and uniform-comparison forms, and geometry exit-setup validation. Geometry and call-lowering work is being handled separately; this sweep does not bypass those checks. Mesh and task allocations are preserved but remain context gaps rather than being mislabeled as ordinary vertex programs.

Reproduce

See the static archive workflow. The tools preserve source provenance and distinguish missing, inferred, and synthetic context. Their reports retain failures rather than treating omitted sources as passes.

Checks

The standalone compiler/exporter build and all four CTest suites passed. The Python reader and coverage suite has 24 passing tests. On Windows the NUP exporter passed 12 tests; its symlink test was skipped because symlink creation was unavailable. The equivalent Linux test passed. Each production fix also has captured-word regressions and independent before/after corpus replay in its own PR.

The previous sweep tables mislabeled 0400C3F00006E000 as Fire Emblem. That ID is Mario Kart World; Fire Emblem is 04007EF01F8AE000. The mapping and historical table labels are corrected here without changing their recorded counts.
